# Marmoraria

Site institucional de uma marmoraria, criado com Hostinger Horizons para apresentar os serviços da empresa e facilitar o contato com clientes.

## Como rodar localmente

Com o Node.js e o npm instalados, abra um terminal na raiz do projeto e execute:

```bash
npm install
npm run dev
```

Abra o endereço `localhost` informado no terminal. Para encerrar o servidor, pressione `Ctrl + C`.

## Estrutura do projeto

- `apps/` — código das aplicações do projeto.
- `package.json` — dependências e comandos disponíveis na raiz.
- `.nvmrc` — versão do Node.js indicada pelo projeto.![Uploading 2550a107-b125-42e5-bac7-fe2777ae912f.png…]()
