# Marmoraria Lumina

Site institucional da Marmoraria Lumina, criado com Hostinger Horizons para apresentar materiais, serviços e projetos e facilitar a solicitação de orçamentos.

## Prévia do site

![Mockup do site da Marmoraria Lumina em um monitor e em um celular](./mockup-marmoraria.png)

## Como rodar localmente

Com o Node.js e o npm instalados, abra o terminal na raiz do projeto e execute:

```bash
npm install
npm run dev
```

Abra o endereço `localhost` mostrado no terminal. Para encerrar o servidor, pressione `Ctrl + C`.

## Estrutura do projeto

- `apps/web/` — aplicação web.
- `apps/api/` — código da API.
- `package.json` — dependências e scripts da raiz do projeto.
- `.nvmrc` — versão do Node.js indicada pelo projeto.
